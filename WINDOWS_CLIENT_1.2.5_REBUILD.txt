WorkshopOS Windows client 1.2.5 - rebuild on Windows
====================================================

Banner must show: Client 1.2.5

Changes in 1.2.5:
- Proper Tickets helpdesk UI (Work -> Tickets, New ticket CTA, filters, detail workflow)
- Crisp dark mode (solid surfaces, not blurry grey)
- Roles dropdown fixed in Settings -> Users & Roles (GET /api/roles)

From repo root (Developer PowerShell for VS 2022):

  git pull origin main

  powershell -ExecutionPolicy Bypass -File .\packaging\build-client.ps1 -Configuration Release -Version 1.2.5 -SkipInstaller

Or wipe + verify + build + launch:

  powershell -ExecutionPolicy Bypass -File .\packaging\rebuild-client.ps1

Outputs:
  packaging\dist\WorkshopOS-Client-win-x64-v1.2.5.zip
  packaging\dist\WorkshopOS-Setup-1.2.5.exe  (if Inno Setup 6 installed)
