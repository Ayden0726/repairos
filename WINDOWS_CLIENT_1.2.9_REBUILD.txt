WorkshopOS Windows client 1.2.9 - rebuild on Windows
====================================================

Banner must show: Client 1.2.9
Build script banner must show: WorkshopOS client build script v6

1.2.9 fixes:
- Quote Builder loads/searches existing customers (GET /api/customers)
  like New Ticket; combo shows name · phone · email · id
- Quote Builder loads Settings → Pricing and applies defaults;
  preview/create use server saved settings (not sticky 20%/50)

From repo root — use Developer PowerShell for VS 2022 (so MSBuild is found):

  git pull origin main

  powershell -ExecutionPolicy Bypass -File .\packaging\build-client.ps1 -Configuration Release -Version 1.2.9 -SkipInstaller

Or wipe + verify + build + launch:

  powershell -ExecutionPolicy Bypass -File .\packaging\rebuild-client.ps1

On failure, read:
  packaging\out\logs\publish-last.log

Outputs:
  packaging\dist\WorkshopOS-Client-win-x64-v1.2.9.zip
  packaging\dist\WorkshopOS-Setup-1.2.9.exe  (if Inno Setup 6 installed)
