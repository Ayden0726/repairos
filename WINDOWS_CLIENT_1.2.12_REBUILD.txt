WorkshopOS Windows client 1.2.12 - rebuild on Windows
=====================================================

Banner must show: Client 1.2.12
Build script banner must show: WorkshopOS client build script v6

1.2.12 adds:
- Refurbished (Used Tech) list + create/edit with full device, cost, condition, status fields
- Margin column when pricing.view is allowed
- Server migration for brand/model/category/colour/storage/specs/notes/source/links

IMPORTANT — update the SERVER first (migration + API):

  cd ~/workshopos
  git pull origin main
  ./scripts/restart-workshopos.sh --update

Then rebuild the Windows client:

  git pull origin main

  powershell -ExecutionPolicy Bypass -File .\packaging\build-client.ps1 -Configuration Release -Version 1.2.12 -SkipInstaller

Or wipe + verify + build + launch:

  powershell -ExecutionPolicy Bypass -File .\packaging\rebuild-client.ps1

On failure, read:
  packaging\out\logs\publish-last.log

Outputs:
  packaging\dist\WorkshopOS-Client-win-x64-v1.2.12.zip
  packaging\dist\WorkshopOS-Setup-1.2.12.exe  (if Inno Setup 6 installed)
