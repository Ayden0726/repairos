WorkshopOS Windows client 1.2.7 - rebuild on Windows
====================================================

Banner must show: Client 1.2.7

Changes in 1.2.7:
- Shell header Alerts text replaced with bell icon + notifications flyout
- Auto-dismiss notification InfoBar banner when new alerts arrive
- Dashboard greeting (Good morning/afternoon/evening + tech name)
- Dashboard quick view: open tickets assigned to the signed-in technician

From repo root (Developer PowerShell for VS 2022):

  git pull origin main

  powershell -ExecutionPolicy Bypass -File .\packaging\build-client.ps1 -Configuration Release -Version 1.2.7 -SkipInstaller

Or wipe + verify + build + launch:

  powershell -ExecutionPolicy Bypass -File .\packaging\rebuild-client.ps1

Outputs:
  packaging\dist\WorkshopOS-Client-win-x64-v1.2.7.zip
  packaging\dist\WorkshopOS-Setup-1.2.7.exe  (if Inno Setup 6 installed)
