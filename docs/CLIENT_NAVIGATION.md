# Windows Client Navigation

## Shell chrome

- Left sidebar modules from `/api/settings/modules`
- Top: global search, Notifications shortcut, user menu
- Header: **WorkshopOS** + configured business name

| --- | --- |

| Notifications | Inbox list |
