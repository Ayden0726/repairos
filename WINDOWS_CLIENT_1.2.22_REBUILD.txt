WorkshopOS Windows client 1.2.22 - rebuild on Windows

Banner must show: Client 1.2.22

Root cause of 1.2.21 publish failure (CS0101):
  ServicePickerControl.xaml.cs AND ServiceCataloguePickerLogic.cs both
  defined CatalogueServiceRow. Zip Expand-Archive -Force does NOT delete
  leftover files, so ServicePickerControl survived after the 1.2.21 overlay.

1.2.22 fix:
  - ServicePickerControl.xaml + .xaml.cs must be ABSENT
  - Only ServiceCataloguePickerLogic.cs owns CatalogueServiceRow
  - Wipe apps\windows-client\WorkshopOS.Client\obj before publish
  - Rebuild script asserts picker files are gone

  powershell -ExecutionPolicy Bypass -File .\packaging\build-client.ps1 -Configuration Release -Version 1.2.22
